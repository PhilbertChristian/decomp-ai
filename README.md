# Decomposition AI

Demo landing page for **Decomposition AI** — lead enrichment as typed functions. It breaks websites (LinkedIn, Crunchbase, company sites, job boards) into callable APIs so agents can enrich leads without a browser.

Static site, no build step: `index.html`, `styles.css`, `app.js`.

## Run locally

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765.

## Sections
- Hero with install snippet
- Provider examples (LinkedIn, Crunchbase → typed code)
- Animated comparison: Decomposition AI vs. a browser agent (4 enrichment tasks)
- Function catalog marquee
- Install / setup tabs (MCP, Node, Python, HTTP)
- "How a website becomes functions" (6-step animated pipeline)
- Team/enterprise and FAQ

All data shown is mock demo data.
