The web wasn't built for AI agents.

So today agents use it like a person would: open a browser, look at the screen, click, wait, read. That's slow and expensive. Decomposition AI skips the screen entirely.

How it works

What does "decomposing" a website actually do?

Every website is a thin layer of pixels over a few small data requests. Browser agents work on the pixels. Decomposition AI works on the requests underneath.

What you see
Rendered pagePixels, buttons, pop-ups, cookie banners
~1,500 tokens per screenshot
× every step
← browser agents read this
What the browser downloads
HTML + JavaScript + CSSLayout, tracking scripts, ads, fonts
~2.4 MB · 40k+ tokens of DOM
What the page actually needed
One data requestGET /api/company?domain=northwind.ai → JSON
~3 KB · ~300 tokens
← Decomposition AI calls this

Decomposing = finding those underlying requests once, and wrapping them as typed functions your agent can call directly.

      Where the savings come from.

      There's no magic, just four things a browser agent has to do and we don't.

      ~40×
      Fewer tokens per step

      The model reads a 3 KB JSON answer, not a 2 MB page or a stack of screenshots. Tokens are what you pay for.

      ~4×
      Fewer LLM round trips

      A browser agent has to stop and think before every click: look, decide, click, wait, look again. A function call is one step.

      ~200 ms
      No browser to run

      A plain HTTP request instead of booting Chrome, loading scripts and waiting for renders. Run hundreds in parallel on a laptop.

      ~0
      Retries from UI breakage

      No captchas, pop-ups, layout changes or lost sessions. Responses are checked against a typed schema, so bad data fails loudly.

      1,000

      Assumes ~$0.90 and ~4 min per lead for a browser agent vs ~$0.02 and ~2.5 s with Decomposition AI. These are illustrative estimates, not measured benchmarks.

      Where do the leads come from?

      Your existing Pipedrive Sponsors pipeline. Decomposition AI only picks up deals in the "Replied" stage, so effort goes to leads who asked for more.

      What does enrichment add?

      The contact's role, company stage and funding, recent launches or news, and which part of your audience matches their ICP.

      Why no pricing on the page?

      Leads who ask for information convert better on a call. The page shows packages; pricing is presented live with the sponsor kit.

      Does it send emails for me?

      No — it drafts. You review and send from your own inbox.

      Is this a scraper?

      No. It calls the same endpoints each site's own front-end uses and returns structured, typed data.
