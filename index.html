Fair questions.

Is this a scraper?

No. Instead of rendering pages and parsing HTML, Decomposition AI calls the same underlying endpoints a site's own front-end uses, returning structured, typed data.

What does a single enrichment return?

Person (title, seniority, LinkedIn, work email confidence), company (headcount, funding, tech stack, HQ) and buying signals (hiring, funding, leadership changes).

Which agents does it work in?

Anything that speaks MCP, plus a Node and Python SDK and a plain HTTP API.

What does it cost?

Free to start, then metered per enriched record.

What if a source I need isn't covered?

Request it — new sources are decomposed automatically and reviewed before release.
